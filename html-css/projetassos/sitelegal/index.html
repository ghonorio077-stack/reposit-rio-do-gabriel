Teste de Flexbox & Transições - Bloco 1

Clique no ícone de menu no modo mobile (ou diminuindo a largura da janela) para observar a abertura e o fechamento com transição suave de 0.5s.

Para conseguir esse efeito, em vez de alterar a propriedade display diretamente (que impede animações), usamos uma combinação de max-height, opacity e transform: translateY().

Demonstração Responsiva - Bloco 2

Quando a tela é redimensionada de volta para o tamanho Desktop (acima de 768px), o código remove automaticamente o estado aberto do menu mobile, garantindo que o cabeçalho volte ao seu layout horizontal original sem erros de layout.
